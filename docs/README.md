# VisionAir

VisionAir is a human-centered governed intelligence environment that helps capable but unclear people turn what they already carry into something structured, trustworthy, and real.

## Current Product Focus
VisionAir is being rebuilt from first principles around one core truth:

> capable but unclear people do not mainly need more inspiration — they need a structured, trustworthy path that helps them move.

This repository exists to build that path.

## First User
VisionAir is built first for:

**the capable but unclear nontechnical builder**

Someone who:
- has real ability, insight, or potential
- knows there is something meaningful inside them
- wants to build something real
- lacks structure, direction, trusted progression, or technical leverage

## First Sacred Experience
VisionAir must first prove one sacred experience:

> a capable but unclear person enters in fog and leaves with a structured, trustworthy sense of what they have, who it helps, what it should become, and what to do next.

## Core Product Promise
VisionAir helps capable but unclear people turn internal possibility into structured agency.

More fully:

> VisionAir helps capable but unclear nontechnical builders move from unstructured potential to structured, trustworthy progress so they can bring something real into the world.

## Development Doctrine
VisionAir is not being built as:
- a generic AI idea generator
- a startup productivity tool
- a business-plan machine
- a hype-driven founder app
- a broad platform before the core experience is proven

VisionAir is being built as:
- a governed progression environment
- a guided intelligence system
- a product that reduces fog
- a product that preserves trust
- a product that restores movement

## Build Rule
Build only what strengthens the first sacred experience.

If a feature does not help the first user move from fog to structured agency, it does not belong yet.

## Repo Priorities
Current repo priorities are:
1. preserve product truth
2. prove the first sacred experience
3. strengthen synthesis quality
4. produce a trustworthy artifact
5. create real next-step movement
