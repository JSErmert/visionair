### File added — `app/session/flow/lane-derivation.ts` (571 lines)
Pure-deterministic lane-derivation module. No React/Next imports. Imports v1.1.2 detectors (themes, capability targets, version-one form, scope, ideal-user role, ideal-user blocker) for signal extraction; defines its own marker tables locally (per realignment hard stop on vocabulary expansion in `structural-primitives.ts`).

**Public exports:**
- Types: `CognitiveLane` (6 values), `ConstraintLane` (5 values), `GuidanceLane` (5 values), `LaneConfidence`, `LaneEvidence` (T3), `LaneProfile`
- Constant: `LANE_SELECTION_THRESHOLD = 0.55` (T1)
- Functions: `deriveLaneProfile(state: SessionState): LaneProfile`, `getLaneAwareFallback(profile?: LaneProfile): LaneAwareFallback | null` (T2 gates on `confidence === 'high'`)

**Local marker tables (not added to primitives):**
- `metaOrchestratorMarkers` (8 patterns) — across-projects, multiple-systems, digital-brain, orchestration-layer, intelligence-layer, portfolio-intelligence, knowledge-graph, meta-system
- `abstractSystemsMarkers` (8 patterns) — principle, dynamic, transformation, systems-thinker, deeper-structure, underlying-pattern, highly/deeply-intellectual, polymath
- `legibilityGapMarkers` (7 patterns) — under-recognized/valued, cannot-find-employment, people-don't-understand, hard-to-explain/present/translate, cannot-present/show/translate, not-recognized, others-cannot-see
- `ambitionMarkers` (7 patterns) — ambitious, scale, massive, world-class/wide/changing, millions/thousands-of, huge-impact/opportunity/market, big-idea/vision/impact (T4 support)
- `uncertaintyMarkers` (8 patterns) — not-sure, don't-know-what/where/how/whether, unsure, maybe, build-yet (with optional something/anything), someday, something-like, vague-idea (T5 support)
- `understructuredMarkers` (6 patterns) — do-a-lot, built-things, hard-to-explain, don't-know-how-to-explain/describe/name, all-over-the-place, nothing-clearly-shaped

**Pipeline (5 stages):**
1. `extractSignals(joined)` — runs all detectors and counters; produces `SignalSet`
2. `scoreCognitive` / `scoreConstraint` — weighted contributions per lane, scores in [0, 1]
3. `scoreGuidance` — depends on resolved cognitive + constraint lanes (downstream-aware)
4. `resolveLane` — picks top score ≥ threshold (0.55 per T1) with deterministic lexical tie-break; returns `null` if `uncertaintyMarkers ≥ 2` (T5 support)
5. `deriveConfidence` — `high` (sum ≥ 1.8 + max ≥ 0.6) / `medium` (sum ≥ 1.0 + max ≥ 0.5) / `low`; uncertainty-dominated inputs forced to `low`

**Lane-aware fallback maps (sparse):**
Five populated cognitive×constraint pairs covering the v1.1.0 user-testing observation classes:
- `high_capability_low_legibility | legibility_gap` — idealUser, capability, before
- `meta_orchestrator | scope_gap` — versionOne, before
- `abstract_systems_thinker | structure_gap` — before, versionOne
- `ambitious_unstructured_builder | scope_gap` — versionOne, before (T4)
- `understructured_operator | legibility_gap` — capability, idealUser

Other cognitive×constraint pairs fall through to existing generic fallback. T2 gates: `getLaneAwareFallback` returns `null` unless `confidence === 'high'`.

### Pre-execution memo-pass refinements
After initial implementation surfaced two test failures, two further tightenings were applied (within the same execution pass, not a separate re-seal):

- **`scope_gap` constraint scoring rebalanced** — the original `0.6 * (formNoun === null && scope === null) + 0.4 * (targets.length === 0)` formulation fired too eagerly for any input lacking a form noun. Replaced with a building-theme-gated formulation: `0.4 * (building && !formNoun) + 0.4 * (no scope && building) + 0.2 * (no targets)`. Now `scope_gap` only fires when build intent is present, which is the operationally meaningful case.
- **`uncertaintyMarkers` "build yet" pattern broadened** — original `\b(?:want\s+to\s+)?build\s+(?:something|anything)\s+yet\b` required "something/anything" between "build" and "yet"; updated to make those optional via `\b(?:want\s+to\s+)?build(?:\s+(?:something|anything))?\s+yet\b`. Catches "what I want to build yet" without the connector word.

These are bounded internal corrections to the artifact's specified scoring shape, not new feature work; they were necessary to satisfy V5e and were applied before V5d/V5e re-validation.
