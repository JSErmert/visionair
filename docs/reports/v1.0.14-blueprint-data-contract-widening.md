**`SectionCard` accepts `string | string[]`** and renders bullet lists for arrays while keeping paragraph rendering for strings:

```tsx
function SectionCard({
  title,
  content,
}: {
  title: string
  content: string | string[]
}) {
  const isArray = Array.isArray(content)
  const hasContent = isArray ? content.length > 0 : content.trim().length > 0

  return (
    <div className="rounded-2xl border border-black/10 bg-white p-5">
      <p className="mb-2 text-sm font-medium tracking-wide text-black/55">
        {title}
      </p>
      {hasContent ? (
        isArray ? (
          <ul className="space-y-2">
            {content.map((item, i) => (
              <li key={i} className="text-base leading-7 text-black/80">
                • {item}
              </li>
            ))}
          </ul>
        ) : (
          <p className="text-base leading-7 text-black/80">{content}</p>
        )
      ) : (
        <p className="text-base leading-7 text-black/80">Still taking shape.</p>
      )}
    </div>
  )
}
```

Structural parallel to `transformation.tsx:177-204` (same `<ul className="space-y-2">`, same `<li>` + `•` pattern). Text sizing kept at `text-base leading-7` to match the blueprint card's existing visual weight rather than transformation's denser `text-sm`. "Still taking shape." empty state preserved for both string and array paths.
