# Scope Denylist Extension — Re-Seal with First-Word-Check Design (bug_011 closure)

## Report Version
v1.0.21 (second re-seal — first-word-check design; bug_011 closed)

## Purpose
Close bug_011 by extending the exclusion denylist from 6 to 23 tokens AND changing the denylist-check logic from full-match to first-word-of-capture. Supersedes the first re-seal of v1.0.21 (documented in `docs/reports/v1.0.21-scope-denylist-extension.md`), which executed and failed V5 synthetic validation because the regex captures up to 2 words greedily while the denylist filtered only single tokens. This re-seal fixes the filter logic so the denylist filters based on the first word of each capture, regardless of whether the capture is 1 or 2 words.
