### Pattern-quality observations (for v1.0.18+ polish pass, not blocking)

1. **P1 context pattern missed "incidents" (plural), "on-call" (hyphenated), "gets paged" (tense).** Regex `\bincident\b` requires word boundary; "incidents" has `s` after. Regex `on\s+call\b` requires space; input uses hyphen. Regex `getting\s+paged` requires gerund; input uses "gets paged." Fix: `incidents?\b`, `on[\s-]+call\b`, `(?:get|gets|got|getting)\s+paged\b`.
