# VisionAir Product Requirements Document  
  
## Product Name  
VisionAir  
  
## Product Category  
Human-centered AI orchestration product  
  
## One-line Product Definition  
VisionAir is a guided intelligence environment that helps capable but unclear people turn what they already carry into a structured, trustworthy path they can begin building.  
  
## Product Essence  
VisionAir is not just an idea tool, startup assistant, or business planner. It is a governed progression system designed to help a person move from vague internal potential to structured agency.  
  
It exists to help people who know there is something real inside them — a skill, a direction, a capability, an idea, a business impulse — but who do not yet have a clear, trustworthy path for making it real.  
  
---  
  
## Primary User  
  
### First Core User  
A skilled but unstructured nontechnical person who knows they have something valuable to offer, but does not yet have a clear, trusted path for turning it into something real.  
  
### User Traits  
- capable but unclear  
- nontechnical or not highly technical  
- has real skill, insight, or potential  
- wants to build something meaningful  
- feels blocked by lack of structure, direction, or technical leverage  
- may have one idea, several ideas, or only a strong sense that something is there  
  
### Core User Pain  
The user is not empty. They are unstructured.  
  
Their pain is:  
- fog  
- overthinking  
- lack of direction  
- inability to translate inner capability into outer form  
- lack of trusted progression  
- dependence on technical or structural gatekeepers  
- the emotional burden of unrealized potential  
  
### Core User Desire  
- clarity  
- structure  
- direction  
- trusted movement  
- a path that fits who they are  
- something real they can begin building  
  
---  
  
## Core Product Promise  
VisionAir helps capable but unclear nontechnical builders move from unstructured potential to structured, trustworthy progress so they can bring something real into the world.  
  
---  
  
## Core Transformation  
  
### Before VisionAir  
The user feels:  
- capable but scattered  
- thoughtful but unclear  
- inspired but overwhelmed  
- full of potential but unable to structure the next move  
- trapped in possibility without a path  
  
### After VisionAir  
The user feels:  
- seen  
- clearer  
- more aligned  
- more structured  
- more confident in what they have  
- able to move toward something real  
  
### Transformation Statement  
VisionAir transforms unstructured potential into structured agency.  
  
---  
  
## Emotional Arc of the First Session  
The first session should move the user through:  
  
**Relief -> Recognition -> Alignment -> Belief -> Agency**  
  
### Emotional Promise  
VisionAir should make the user feel that what was once vague, internal, and difficult to trust has now become visible, structured, and possible to act on.  
  
---  
  
## MVP First Experience Name  
Structured Opportunity Session  
  
## MVP Session Goal  
Take a capable but unclear nontechnical builder from:  
  
**"I know there’s something here, but I can’t structure it."**  
  
to:  
  
**"I can clearly see what I have, who it helps, what it should become, and what my first real move is."**  
  
---  
  
## Core Output  
  
### Structured Opportunity Blueprint  
The first session generates a 7-part artifact:  
  
1. Core Capability  
2. Aligned Problem Space  
3. Ideal User  
4. Transformation Promise  
5. Opportunity Form  
6. First Buildable Version  
7. Guided Path Forward  
  
### Blueprint Definition  
The Structured Opportunity Blueprint is a guided output that translates a person’s real capability into an aligned problem space, a clear user, a meaningful transformation, the right opportunity form, a first buildable version, and a trustworthy next path forward.  
  
---  
  
## The 7 Blueprint Sections  
  
### 1. Core Capability  
What the user is genuinely good at.  
  
Captures:  
- strongest real abilities  
- natural value pattern  
- repeated problem-solving instincts  
- what comes most intuitively  
  
### 2. Aligned Problem Space  
What kind of real-world problem their capability should be aimed at.  
  
Captures:  
- meaningful problem domain  
- where their capability creates leverage  
- the type of issue they feel called to improve  
  
### 3. Ideal User  
Who most needs the value they create.  
  
Captures:  
- first exact person to help  
- their current stuckness  
- what they need but are not getting  
- why this user is the right first focus  
  
### 4. Transformation Promise  
What changes for that person because this system exists.  
  
Captures:  
- before state  
- after state  
- emotional shift  
- practical shift  
- the value created  
  
### 5. Opportunity Form  
What shape the opportunity should take.  
  
Possible forms:  
- guided digital platform  
- service  
- tool  
- hybrid system  
- guided experience  
- educational environment  
  
### 6. First Buildable Version  
What version one actually is.  
  
Captures:  
- smallest meaningful version  
- what must be included first  
- what should wait  
- what proves value  
  
### 7. Guided Path Forward  
What to do next.  
  
Captures:  
- immediate next steps  
- near-term validation path  
- later-stage items to postpone  
- momentum with discipline  
  
---  
  
## Product Intelligence Model  
VisionAir should not behave like a questionnaire.    
It should behave like a guided intelligence conversation.  
  
### The system should:  
- reflect back patterns  
- identify recurring language  
- notice contradictions  
- surface strongest signals  
- ask follow-up questions when answers are vague  
- narrow the path without becoming rigid  
- preserve the user’s language when it contains truth  
  
### Guiding principle  
The user should not need to be fully clear upfront.    
VisionAir exists to help create that clarity.  
  
---  
  
## Core Session Flow  
  
### 1. Welcome / Permission to Begin  
Reduce pressure and invite honest entry.  
  
### 2. Starting Point Selection  
Let the user begin from what feels most real.  
  
### 3. Seed Prompt  
Capture the first true signal.  
  
### 4. Reflection Back  
Create the first recognition moment through intelligent reflection.  
  
### 5. Capability Clarification  
Reveal the user’s value pattern through lived truth.  
  
### 6. Emerging Capability Pattern  
Turn answers into structured self-understanding.  
  
### 7. Problem Space Discovery  
Find where the capability most wants to be applied.  
  
### 8. Ideal User Builder  
Turn the problem into a person.  
  
### 9. Transformation Promise  
Define the movement the system creates.  
  
### 10. Opportunity Form  
Choose the right container for the value.  
  
### 11. First Buildable Version  
Prevent overbuilding and define version one.  
  
### 12. Blueprint Reveal  
Deliver the Structured Opportunity Blueprint.  
  
### 13. Guided Path Forward  
Turn clarity into real movement.  
  
### 14. Closing Reflection  
Leave the user with dignity, belief, and agency.

## UX Principles  
  
### 1. One major task per screen  
Every screen should do one thing well.  
  
### 2. Calm over intensity  
The product should feel spacious, intelligent, and trustworthy.  
  
### 3. Guided, not interrogative  
Questions should feel like discovery, not assessment.  
  
### 4. Truth before branding  
The product should draw out lived reality, not ask users to self-market.  
  
### 5. Progressive synthesis  
Clarity should build step by step.  
  
### 6. Reflection as product value  
The system’s reflections are part of the transformation.  
  
### 7. Movement over admiration  
The session must end in action, not just insight.  
  
---  
  
## Design Tone  
The interface should feel:  
- calm  
- spacious  
- premium but warm  
- intelligent  
- structured without being rigid  
- emotionally safe  
- human-centered  
  
### It should not feel like:  
- a startup dashboard  
- a form wizard  
- a productivity app  
- a cold AI chat window  
- a loud entrepreneurial hype product  
  
---  
  
## Core Copy Principle  
VisionAir should speak like a calm, perceptive guide.    
Not like a generic assistant.    
Not like a high-energy founder coach.    
Not like a therapist.  
  
It should feel like:  
- reflective  
- lucid  
- serious  
- respectful  
- clear  
- deeply structured

## MVP Scope  
  
### In scope  
- first session flow  
- capability clarification  
- aligned problem selection  
- user and transformation definition  
- opportunity form recommendation  
- version-one grounding  
- blueprint generation  
- guided next steps  
  
### Acceptable for prototype  
- manual or mocked synthesis  
- static blueprint reveal  
- export preview without full backend  
  
### Out of scope for first prototype  
- advanced memory across multiple sessions  
- collaboration features  
- full business-model generation depth  
- complex account system  
- advanced branching engine  
- ecosystem/community layer  
  
---  
  
## Success Criteria  
The MVP succeeds if users leave saying:  
- I feel clearer  
- this understands me surprisingly well  
- I can see what I actually have  
- this path fits me  
- I know what to do next  
  
### It fails if users say:  
- this was interesting but vague  
- this felt like a questionnaire  
- I still don’t know what I actually have  
- the output felt generic  
- I feel inspired, but not more able to move
