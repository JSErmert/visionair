# VisionAir Session Flow

## Purpose
This document defines the first full VisionAir session flow.

It governs the user journey from first entry to final artifact reveal.

This is not just UX flow.
It is transformation flow.

The session must move the user from:

**"I know there’s something here, but I can’t structure it."**

to:

**"I can clearly see what I have, who it helps, what it should become, and what my first real move is."**

---

## Session Name
**Structured Opportunity Session**

## Core Output
**Structured Opportunity Blueprint**

## Emotional Arc
**Relief -> Recognition -> Alignment -> Belief -> Agency**

---

## Session Overview
The session is designed to help a capable but unclear nontechnical builder:

1. begin safely
2. reveal real signal
3. understand their capability
4. align to a meaningful problem space
5. identify who they help
6. define the transformation they create
7. choose the right form
8. ground version one
9. receive a structured artifact
10. leave with movement

---

## Full Session Sequence

### 1. Welcome / Permission to Begin
**Purpose:** lower pressure immediately

The user should feel:
- safe to begin
- not judged
- not behind
- not too vague to start

The system communicates:
- no perfect idea is required
- something real is enough
- structure will emerge through the process

**Emotional goal:** Relief

---

### 2. Starting Point Selection
**Purpose:** let the user begin from what feels most true

The user chooses one starting point:
- something I’m good at
- a problem I care about
- an idea I can’t stop thinking about
- a direction I want to explore
- I’m not sure yet — help me find it

This lets the product meet the user where they are.

**Emotional goal:** honest entry

---

### 3. Seed Prompt
**Purpose:** extract the first true signal

The system asks a tailored open-ended question based on the user’s entry point.

The user responds in natural language.

The goal is not precision yet.
The goal is signal.

**Emotional goal:** invited expression

---

### 4. Reflection Back
**Purpose:** create the first recognition moment

VisionAir reflects back:
- capability signals
- problem signals
- motivation signals

The user confirms, refines, or corrects the reflection.

This is one of the highest-value trust moments in the entire experience.

**Emotional goal:** Recognition

---

### 5. Capability Clarification
**Purpose:** reveal the user’s real value pattern

The system asks guided questions such as:
- when have you felt most capable?
- what do people come to you for?
- what feels natural to you that is difficult for others?
- what kind of value do you repeatedly create?

The goal is not a list of strengths.
The goal is a visible pattern of value creation.

**Emotional goal:** deeper recognition

---

### 6. Emerging Capability Pattern
**Purpose:** synthesize self-understanding into structure

VisionAir generates an emerging capability pattern.

This should help the user feel:
- seen more clearly
- less random
- more coherent
- more able to trust what they actually have

**Emotional goal:** Recognition consolidating into clarity

---

### 7. Problem Space Discovery
**Purpose:** find where the user’s capability most meaningfully belongs

VisionAir surfaces a few aligned problem directions.

The user:
- chooses one
- ranks options
- or refines them

The product narrows toward the most meaningful and fitting problem space.

**Emotional goal:** Alignment beginning

---

### 8. Ideal User Builder
**Purpose:** turn the problem into a person

The system helps the user define:
- who most needs this first
- what that person is struggling with
- why the user understands them
- what that person needs but is not getting

This turns abstract direction into human focus.

**Emotional goal:** relational clarity

---

### 9. Transformation Promise
**Purpose:** define what changes because the system exists

VisionAir guides the user through:
- before state
- after state
- emotional shift
- practical shift
- what real movement looks like

This defines the heart of the value.

**Emotional goal:** Meaning

---

### 10. Opportunity Form
**Purpose:** choose the right container

VisionAir helps determine whether this should begin as:
- a service
- a product
- a platform
- a guided experience
- an educational environment
- a hybrid model

The product recommends the form that best fits:
- the user’s capability
- the problem
- the ideal user
- buildability

**Emotional goal:** Fit

---

### 11. First Buildable Version
**Purpose:** prevent overbuilding and make version one real

The system helps the user define:
- the smallest meaningful version
- what must be included first
- what can wait
- what proves the value is real

This is the moment possibility becomes buildable.

**Emotional goal:** Belief

---

### 12. Blueprint Reveal
**Purpose:** deliver the first core artifact

VisionAir assembles the session into the **Structured Opportunity Blueprint**:

1. Core Capability
2. Aligned Problem Space
3. Ideal User
4. Transformation Promise
5. Opportunity Form
6. First Buildable Version
7. Guided Path Forward

The user should feel:
- this came from me
- this feels real
- this is clearer than what I could have structured alone

**Emotional goal:** Belief + Relief

---

### 13. Guided Path Forward
**Purpose:** end in movement, not admiration

VisionAir provides three layers of next steps:

#### Immediate
What to do in the next 24–72 hours

#### Near-Term
What to validate, shape, or test next

#### Later
What to deliberately postpone

The user leaves with:
- motion
- sequence
- reduced overwhelm
- a path they can begin

**Emotional goal:** Agency

---

### 14. Closing Reflection
**Purpose:** preserve dignity, clarity, and momentum

The session ends by reinforcing:
- what the user now understands
- what has become visible
- what comes next
- that they do not need to build everything at once

The closing should feel calm, hopeful, and grounded.

**Emotional goal:** completed movement

---

## Session Design Rules

### Rule 1
Each screen should do one thing clearly.

### Rule 2
The user should never feel judged, stupid, or too vague to continue.

### Rule 3
Every question should reduce fog.

### Rule 4
The experience must feel guided, not interrogative.

### Rule 5
The final output must feel authored, not generic.

### Rule 6
The user must leave with movement, not just inspiration.

---

## Success Condition
The session succeeds when the user can honestly say:

- I finally understand what I have
- I know who it helps
- I know what it should become
- and I know what I can do next

---

## One-line Session Definition
**VisionAir’s first session is a guided orchestration experience that helps a capable but unclear person move from vague internal potential to a structured, trustworthy path they can begin building.**
