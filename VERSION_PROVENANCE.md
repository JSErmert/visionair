# VisionAir — Version Provenance

A standing record of which version of VisionAir produced which artifact, so it is
always unambiguous what a given output was generated by. Established 2026-06-09.

## v2 — Build Mode (portfolio-genesis version)

- **Tag:** `visionair-v2`
- **Branch at seal:** `feat/build-mode-context-engine`

**What it is:** VisionAir's first context-pack engine. Build Mode runs a
coverage-driven adaptive interview (asking only about what is missing), then
synthesizes, reconciles, and assembles a downloadable, ready-to-build context
pack for AI coding agents (Claude Code and others). Single-owner persistence on
Neon Postgres with an **optional login**: anyone can generate and download a pack;
logging in saves it to the owner's library. The front door (`/`) is a
Build-Mode-only landing. The `/session` guided blueprint flow remains in the repo
but is unlinked — its components are reused by Build Mode, so it is dormant, not
deleted.

**What v2 produced:** the operator's recruiter **portfolio site**
(`professional-porfolio`) was built in Claude Code from a context pack generated by
this version of Build Mode. That makes the portfolio the first shipped product
traceable to a specific VisionAir version, and this record is the anchor for that
claim.
